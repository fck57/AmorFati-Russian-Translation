# AmorFati-Russian-Translation
Русификатор для мода Doki Doki Amor Fati. Автор: fck57
Это полный фанатский перевод мода *Doki Doki Amor Fati* на русский язык. Перевод выполнялся вручную с использованием современных инструментов, поэтому он полностью бесплатен.

## Установка

1. Скачайте архив `AmorFati_Russian_Patch.rar` из раздела **Releases** (справа на странице репозитория) или скачайте папку `game` напрямую из этого репозитория.
2. Откройте папку с установленной игрой **Doki Doki Amor Fati** (туда, где находится файл запуска `.exe`).
3. Скопируйте папку `game` из архива в папку с игрой.
4. Если Windows спросит о замене файлов, соглашайтесь.

## Важно

- Если вы уже играли в мод, **старые сохранения могут не работать** с переводом. Начните новую игру.
- Если вместо русского текста вы видите квадратики, проверьте, что шрифт лежит в папке `game/fonts/` (или `game/`), и путь в `gui.rpy` указан верно.
- Перевод делался в короткие сроки, поэтому некоторые элементы интерфейса (например, меню сохранений) могут остаться на английском.
